# Locked Landing Layout Reference

Canvas reference: 1536 × 1024.

## Header
- Logo starts around x=76, y=22.
- CTA is top-right.
- Menu icon at far right.
- Header is airy; no boxed nav container.

## Hero
- Main headline begins around x=126, y=178.
- Interviewer image dominates center-right.
- Hero portrait overlaps the editorial composition.
- Question card sits to the right of portrait.
- Flow diagram sits below/right.
- Code card overlaps lower portrait.
- Yellow highlighter is behind “Growth”.
- Handwritten notes frame the hero.
- Checklist sits lower-right.
- Social proof row sits below CTA, left of hero.
- Feature strip begins around y=765.

## Bottom feature strip
Four equal editorial columns:
01 Converse
02 Get Probed
03 Receive Feedback
04 Improve

No card backgrounds around these columns.
Use thin vertical separators and one continuous curved line around the strip.

## Critical
Do not implement the reference screenshot as a single image.
All text and UI must be real HTML.
All decorative marks should be independent SVG/image assets.
